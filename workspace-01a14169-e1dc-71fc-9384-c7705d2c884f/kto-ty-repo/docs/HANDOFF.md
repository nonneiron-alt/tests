# Передача проекта — 16 октября 2026

## Продукт

Название: **кто.ты**. Русский развлекательный сайт с эстетикой старого интернета: повторяющийся фон, гифки, псевдоокна, каталог квизов, «уголок вебмастера».

Сценарий: пользователь задает тему («какой ты гном», «сколько в тебе котов», «кто ты из Genshin Impact»), тема сразу попадает в базу/каталог. Нейросеть задает пять вопросов (четыре варианта или свой текст), учитывает ответы и выдает развернутый индивидуальный результат с картинкой. Результат сохраняется и открывается по ссылке `/#result=<session>`.

## Текущее поручение

Владелец попросил подготовить проект для загрузки в **приватный GitHub** и оставить инструкции следующему агенту. Он отдельно сообщил, что AI выдает нерелевантные результаты. В этой передаче **качество AI еще не исправлялось**. Следующая сессия должна начать с этого, а не с очередного редизайна/упаковки установщика.

Репозиторий здесь не создан и код никуда не загружен. Это чистый комплект исходников для самостоятельной загрузки. Приватность репозитория нужно выбрать в интерфейсе GitHub.

## Что было раньше

1. Созданы статический фронтенд, Python+SQLite backend и API Groq `openai/gpt-oss-120b`.
2. Добавлен отдельный Worker + D1 для Cloudflare. Важно: это другой runtime и отдельная база.
3. В исходной среде Python полный тест механически прошел пять вопросов и сохранил результат. Это не гарантирует семантическое качество.
4. Worker ранее проверялся локально: сборка, D1, каталог, создание темы, валидация и импорт SQLite. Реального доступа к аккаунту Cloudflare владельца не было.
5. Владелец пробовал Windows PowerShell деплой. Были ошибки получения UUID D1 и пустого `$PSScriptRoot` в default-параметре. Появились фиксы и автономный PS1 с файлами, portable Node и встроенным ключом (по явной просьбе владельца).
6. **Подтвержденного успешного завершения деплоя, URL и ID ресурсов в переписке нет.** Не предполагать, что новый код уже в продакшене.
7. Последняя жалоба: AI-результат «полная хрень не связанная с вопросом». Конкретный пример не получен.

## Что подготовлено сейчас

- Чистые `worker.js`, `server.py`, `static/`, `migrations/` и экспорт SQLite.
- `package.json`/lock с Wrangler 4.151.0, Node 22+ (обновлено с 4.86.0 из-за найденных npm audit предупреждений; на момент упаковки новый lock прошел npm audit без известных уязвимостей).
- Локальный Wrangler конфиг без реальных ID и отдельный игнорируемый remote-конфиг, который генерирует `deploy.mjs`.
- Деплой-скрипт читает ключ только из окружения/скрытого ввода, не содержит старого ключа. D1 JSON разбирается в Node, а не PowerShell; поддерживаются вложенные массивы и uuid/database_id/id.
- PowerShell developer wrapper: `deploy.ps1`. Это НЕ старый автономный установщик; требует установленный Node 22+.
- Офлайн контрактные тесты и TODO для семантического качества. Синтетические fixtures.
- Архив намеренно не содержит `quizzes.sqlite3`, реальные сессии, конфиги аккаунта, старый install.ps1 и извлеченный скрипт со встроенным ключом. Облачные данные сюда не экспортировались.

## Карта файлов

- `static/index.html`: главная, форма, каталог, контейнер теста.
- `static/app.js`: `start`, `answer`, `renderQuestion`, `renderResult`; hash-ссылка на результат.
- `static/style.css`: ретро-оформление и адаптив.
- `worker.js`: маршруты, промпты, Groq, Wikipedia, D1.
- `server.py`: альтернативный локальный HTTP server + SQLite + собственные промпты.
- `migrations/0001_schema.sql`: таблицы quizzes/sessions, индекс, шесть starter-тестов.
- `deploy.mjs`: логин/поиск D1/миграция/деплой/secret. Может открывать браузер; это не инструмент диагностики качества.
- `export_sqlite.py`: разовый экспорт локальных таблиц для D1; секреты/данные экспорта не коммитить.
- `tests/`: офлайн smoke/contract и будущие quality cases.

## Данные и ограничения

`quizzes`: id,title,emoji,category,description,image,plays,created.
`ses­sions` (имя SQL-таблицы: `sessions`): id,quiz_id,history,result. history — JSON с answers/current; result — JSON. Вопросы для одной темы генерируются заново при каждом прохождении: это не фиксированный опубликованный опросник.

Аккаунтов и полноценной авторизации нет, результат виден по ссылке. Нет надежной модерации/антибота/rate limiting. `plays` — завершения, не просмотры. Local SQLite не синхронизируется с D1. Картинка может быть приблизительной fallback-фотографией.

## Не делать
