# Один файл для установки кто.ты

Скачайте `install.ps1` в любую папку Windows. Других файлов рядом не требуется.

Откройте в этой папке PowerShell и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Установщик распакует проект в соседнюю папку `kto-ty-site`, скачает переносимый Node.js LTS с официального nodejs.org, проверит SHA256 архива, запустит Wrangler, подключит или создаст D1, применит миграцию, загрузит сайт и сохранит встроенный Groq-ключ в Worker Secret.

**Потребуются интернет и аккаунт Cloudflare.** Авторизацию Cloudflare нужно подтвердить в браузере. Это не офлайн-установщик и не способ обойти вход в аккаунт. Если в аккаунте несколько организаций, может понадобиться выбрать Account ID. При первом использовании Workers Cloudflare может запросить создание workers.dev-поддомена. Для обычного личного Windows-профиля права администратора не нужны; корпоративные политики могут ограничивать запуск скриптов.

Node.js и Python заранее ставить не нужно. Поддерживается 64-битная Windows x64 / ARM64, Windows PowerShell 5.1+ или PowerShell 7. Скрипт запускается из открытой консоли: двойной щелчок по PS1 обычно открывает редактор, а не запускает его.

Ссылка `https://...workers.dev` появится в выводе Wrangler. На сайте уже будут шесть стартовых тестов. Пользовательские темы и результаты сохраняются в Cloudflare D1. Визуальные файлы и API полностью включены в установщик. Groq и Wikipedia вызываются по сети; при отсутствии подходящей картинки есть локальная тематическая фотография.

## Повторный запуск

Запустите ту же команду ещё раз. Файлы сайта обновятся, применённые миграции повторно не исполнятся, облачные тесты и результаты не удалятся. Данные старого локального `quizzes.sqlite3` эта автономная версия автоматически **не переносит**: Python для запуска не нужен. Уже существующая облачная база с тем же именем будет использована.

Установщик заменяет исходники в `kto-ty-site`, поэтому если вы вручную редактировали сайт, сначала сохраните копию правок. Локальная SQLite и D1 не синхронизируются.

## Необязательные параметры

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Name my-retro-quiz
```

Можно также задать `-InstallDir`, `-DatabaseName`, `-DatabaseId` и `-AccountId`. Для существующих ресурсов используйте реальные ID из Cloudflare, не имя базы вместо UUID. На последующих запусках сохраняйте те же параметры.

## Ключ и безопасность

По просьбе владельца в установщик встроен его Groq-ключ. Base64/ZIP — **не шифрование**: любой обладатель файла может его извлечь. Ключ также есть в распакованном `deploy.mjs`; не публикуйте папку проекта или установщик. В `worker.js`, HTML, JS браузера и статических ресурсах ключа нет. Wrangler отправляет его в Cloudflare как серверный секрет, не как параметр CLI. Если ключ был отозван/заблокирован, AI-запросы не заработают до его замены через `wrangler secret put GROQ_API_KEY`.

Нельзя гарантировать доступность внешних API, лимиты тарифа и разрешения вашего аккаунта. Для большого публичного сайта добавьте ограничения запросов и расходов Groq, модерацию и защиту от ботов. Развлекательные тесты не являются психологической диагностикой.

## Проверки

API Workers и D1 ранее проверены в локальном Wrangler runtime. Для автономной версии проверены синтаксис Node-оркестратора, разбор вложенных списков D1, повторное использование базы, сценарий создания базы, альтернативное поле database_id и передача ключа через stdin на тестовом CLI. Авторизация и реальный деплой в ваш Cloudflare выполняются у вас. Windows PowerShell bootstrap требует проверки на вашей Windows-системе.
