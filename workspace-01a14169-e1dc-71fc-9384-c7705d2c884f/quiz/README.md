# кто.ты

Русскоязычный сайт AI-квизов в эстетике раннего интернета.

## Запуск

Нужен Python 3.10+, без сторонних зависимостей.

```bash
cd quiz
export GROQ_API_KEY='ваш_новый_ключ'
python server.py
```

Сервер слушает `0.0.0.0:3000`. Ключ читается только из переменной окружения, не отправляется в браузер и не записывается в исходники.

## Что работает

- Создание темы с немедленной записью в SQLite.
- Общий каталог, категории и поиск.
- 5 вопросов с вариантами или собственным ответом.
- Учет предыдущих ответов, подробный результат и шкалы качеств.
- Groq API, модель `openai/gpt-oss-120b`.
- Поиск картинки через Wikipedia API; резерв — тематическое фото Unsplash.
- Постоянная ссылка на сохраненный результат `/#result=ID`.
- Количество завершений тестов, мобильная верстка, обработка сетевых ошибок.

Данные находятся в `quizzes.sqlite3`. Для публичного развертывания нужна постоянная файловая система, HTTPS, ограничение запросов к API и модерация пользовательских тем. Здесь нет аккаунтов, результаты доступны любому с их ссылкой. Не вводите чувствительные данные. Развлечение, не психологическая диагностика.

Изображения: Unsplash, Wikipedia (источник указан в результате). Гифка глобуса скачана с GifDB: https://gifdb.com/gif/globe-map-earth-spinning-u010rcqedkkodihh.html

API-ключ из чата рекомендуется отозвать после проверки и заменить новым.
